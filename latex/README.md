# Historical architecture diagrams

`architecture.tex`, `figures/*.tex`, and `architecture.pdf` record the
2026-10-16 architecture snapshot. They are preserved experiment documentation.
The current RMS waveform frontend, 1-D task CNN and fixed SGD meta-learning
procedure are documented in [the project README](../README.md).

The PDF can be rebuilt from its original vector sources using `make` in this
directory with a TeX installation providing TikZ/PGF, AMS math and Latin Modern
fonts. The build requires no recordings or training job.
